# A Walk Along the Critical Line

An illustrated, one-idea-per-page tour of the November 2026 Lean proof of the Riemann Hypothesis, for readers who know some calculus and complex numbers.

Read it at **https://aaronrosenthal.github.io/critical-line/**. Use the arrow keys, space or swipe to turn pages, and press C for the contents.

Plain HTML, CSS and JavaScript with no build step. Primes are sieved and ζ is evaluated live in the browser; the first 200 zeros of ζ were precomputed with mpmath. Pages marked "our reading" are interpretations, not claims made by the proof or its author.
